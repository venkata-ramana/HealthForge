# Prior-Authorization Copilot

The Phase 4 prior-authorization copilot is a bounded PAS/CRD/DTR workflow assistant.

## Purpose

Guide reviewers through common prior-authorization scenario analysis by surfacing:

- likely workflow stage
- likely scenario type
- likely personas
- candidate standards touchpoints
- reviewer-visible risks and caveats

## Current scenario handling

The first version infers likely workflow guidance for:

- PAS
- CRD
- DTR
- general prior-authorization scenarios

## Boundary

This workflow:

- does not claim payer-specific support
- does not certify conformance
- does not remove human review
- is intended to hand off into architecture review or approved work-item planning
