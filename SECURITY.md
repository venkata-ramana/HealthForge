# Security policy

Please do not open a public issue for a suspected vulnerability or accidental sensitive-data exposure. Email the repository owner using the contact address shown on the GitHub profile, with a concise reproduction and impact description. We will acknowledge receipt within five business days and coordinate a fix and disclosure timeline.

HealthForge's MVP must not receive PHI, credentials, production records, or other sensitive data. If you believe such data was submitted, stop sharing it and report the incident privately.
