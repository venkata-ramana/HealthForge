# Synthetic FHIR validation fixtures

These examples are a starter fixture library for HealthForge's prior-authorization workflow analysis.

- Every example in this folder is synthetic or otherwise non-sensitive.
- The examples are designed for repeatable local validation and reviewer education.
- They do **not** prove payer-specific conformance, endpoint compatibility, terminology completeness, or production interoperability.

The fixture set intentionally includes both:

- examples expected to validate against pinned base FHIR R4 profiles; and
- examples expected to fail with machine-readable findings that reviewers can inspect.

Use these fixtures to exercise the local validation workflow, compare expected findings, and keep future standards work grounded in a stable non-sensitive dataset.
